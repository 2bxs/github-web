# Herramientas Mesa de Reexpediciones

Sitio estático (HTML/CSS/JS) listo para GitHub Pages.

## Archivos
- `index.html`
- `styles.css`
- `app.js`

## Despliegue en GitHub Pages
1. Sube estos archivos a la raíz del repositorio (o carpeta `docs`).
2. En GitHub: Settings → Pages → Source: branch `main` / folder `/ (root)` (o `/docs`).
3. Guarda y espera el despliegue.

No requiere backend. El valor del dólar aduana se obtiene desde un proxy público con fallback a mindicador.cl y a un valor por defecto.
